# NBA 完美球员

这是 `xytuaaa/my-tools` 的 NBA 球员养成与生涯模拟游戏发布配置。

- 游戏网址：<https://xytuaaa.github.io/my-tools/>
- 游戏参数与机制调整保存在 `patches/perfect-player-balance.patch`
- GitHub Pages 由 `.github/workflows/pages.yml` 自动构建和发布
- 完整生成后的网页文件会保存在 `published` 分支

页面基于原版 [perfect-player](https://github.com/zyz9408/perfect-player) 调整，并保留球迷自制、非 NBA 官方活动的说明。
